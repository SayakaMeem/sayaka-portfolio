## SQL / data evidence used in the portfolio

`Database-CRMS-` is the primary SQL proof point. The repository includes relational schema work and query patterns such as:

- filtering and sorting
- aggregate functions
- `GROUP BY` and `HAVING`
- subqueries
- joins
- set operations
- CTEs
- views
- PL/SQL procedures/functions/triggers

`EthereumHeist-System` is the stronger data-application proof point because it combines transaction data, DuckDB/Pandas tooling, graph-oriented analysis, experiment workflows, and visual presentation.

The website therefore positions the analyst profile around **SQL reasoning + insight + decision framing**, while describing Python as supporting automation/data tooling rather than making Python coding the center of the analyst story.

## Presentation rule

- **Selected Work:** a small curated set with context, technologies, highlights, and role relevance.
- **Repository Explorer:** the complete public archive with search, category filters, repository metadata, and ownership/status labels.

This prevents the two sections from feeling redundant.
